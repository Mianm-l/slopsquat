## 🚨 致命盲区：为什么传统安全工具全部失效？

在 AI 辅助编程时代（ChatGPT、Claude、Cursor、Copilot），大模型在生成代码时经常会**凭空捏造一个不存在的第三方库名**（例如：`flask-super-route-beautifier-ai` 或 `react-easy-responsive-modal`）。

黑客利用自动化脚本持续收集大模型最常幻觉编造的包名，抢先在 **PyPI** 或 **npm** 上注册这些虚假包，并在其构建脚本或主入口中植入恶意代码（窃取环境变量、SSH 密钥、内网凭证）。这种新型供应链攻击被称为 **Slopsquatting（AI 幻觉包抢注投毒）**。

### 为什么 Snyk / Dependabot / pip audit 查不出来？
* **传统 SCA 工具依赖 CVE 漏洞库**：它们只匹配已知公开的 CVE/NVD 数据库。
* **投毒包没有 CVE**：攻击者几天前刚在官方源上架的新包，数据库里根本没有记录！
* **致命误报**：当你运行 `pip audit` 或 `npm audit` 时，它们会极其自信地提示 **`0 vulnerabilities found (安全无风险)`**，导致开发者毫无戒备地安装中招。

**SlopSquat 不依赖落后的 CVE 数据库，而是通过官方源元数据画像与多维启发式模型，直接在毫秒级嗅探出疑似被投毒或未注册的高危幻觉依赖！**

## 🔬 SlopSquat 嗅探机制

SlopSquat 会并发向官方源（PyPI / npm）核验每一个依赖项的“出生证明”与声誉指纹：

| 维度 | 嗅探指标 | 风险判定逻辑 |
| :--- | :--- | :--- |
| 👻 **未注册抢注空窗** | 官方源是否存在？ | 若依赖根本不存在于 PyPI/npm，判定为 **CRITICAL (95分)**。黑客随时可能抢注该名字！ |
| 🍼 **出生天数 (Freshness)** | 注册时间在几天前？ | 注册时间 < 7 天（+45分）；< 30 天（+30分）；而老牌库（> 1 年）大幅减分。 |
| 🏜️ **下载荒漠 (Desert)** | 全球月下载量 | 月下载 < 50 次（+25分）；而数百万下载的明星库大幅减免风险分。 |
| 📦 **孤儿版本 (Single Release)** | 版本发布历史 | 仅发布过 1 个初始版本（v0.0.1 或 v1.0.0，缺乏长期维护记录）。 |
| 🥷 **幽灵仓库 (Ghost Repo)** | 源码与文档 | 官方元数据中没有关联任何有效的 GitHub/GitLab 源码仓库。 |
| 🤖 **AI 幻觉后缀特征** | 命名正则分析 | 命中大模型高频幻觉后缀（`-helper`, `-utils`, `-toolkit`, `-easy`, `-manager` 等）。 |

## 🚀 快速开始

SlopSquat **零外部三方依赖**，纯 Python 3 标准库即可跑通！

### 1. 本地免安装即跑

```bash
git clone https://github.com/Mianm-l/slopsquat.git
cd slopsquat

# 直接扫描你的 requirements.txt
python -m slopsquat path/to/requirements.txt

# 或者直接扫描整个前端/后端项目目录（自动识别 requirements.txt 与 package.json）
python -m slopsquat /path/to/your/project
```

### 2. 全局安装 CLI

```bash
pip install -e .
# 现在可以直接全局使用 slopsquat 命令
slopsquat .
```

## 🛡️ CI/CD & GitHub Actions 门禁

在你的仓库 `.github/workflows/security.yml` 中添加一行，即可在每次 PR 提交或合并时自动阻断恶意依赖：

```yaml
name: Security Guard

on: [pull_request, push]

jobs:
  slopsquat-audit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with:
          python-version: '3.11'
      - name: Install & Scan
        run: |
          pip install git+https://github.com/Mianm-l/slopsquat.git
          slopsquat . --threshold 80
```
> 一旦发现高危幻觉包，命令将以非零状态码（`exit 1`）退出，自动红牌阻断 CI 流程！

## ⚙️ 命令行参数

```text
usage: slopsquat [-h] [--json] [--threshold THRESHOLD] [--strict] [--workers WORKERS] [--ignore IGNORE] [target]

positional arguments:
  target                目标 requirements.txt / package.json 文件或项目目录 (默认: 当前目录)

options:
  -h, --help            显示帮助信息
  --json                输出标准 JSON 数据流，方便与自动化运维脚本对接
  --threshold THRESHOLD 触发告警退出的风险分阈值 (默认: 80)
  --strict              严格模式: 任何 >= 50 分的包均阻断并退出
  --workers WORKERS     并发网络扫描线程数 (默认: 10)
  --ignore IGNORE       白名单跳过的包名列表，用英文逗号分隔
```
